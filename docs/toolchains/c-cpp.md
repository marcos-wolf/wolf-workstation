# C/C++ Toolchain

The wolf-workstation provides a complete native C/C++ development toolchain on Ubuntu.

## Compiler

### GCC

GCC is the primary GNU compiler toolchain.

```bash
gcc --version
g++ --version
```

Current workstation version:

```text
GCC 15.2.0
G++ 15.2.0
```

### Clang

Clang is installed as an alternative compiler and is useful for diagnostics, tooling and LLVM-based development.

```bash
clang --version
clang++ --version
```

Current workstation version:

```text
Clang 21.1.8
```

Both GCC and Clang are available through the standard system paths:

```bash
which gcc
which g++
which clang
which clang++
```

Expected location:

```text
/usr/bin/
```

## Build System

### CMake

CMake is the primary build-system generator.

```bash
cmake --version
```

### Ninja

Ninja is used as the build backend for fast incremental builds.

```bash
ninja --version
```

A typical Debug build is generated with:

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build
```

## Debugging

### GDB

GNU Debugger is the primary command-line debugger.

```bash
gdb --version
```

Typical workflow:

```text
gdb ./build/application
break main
run
next
print variable
continue
quit
```

The workstation was validated with:

* breakpoints
* step-by-step execution
* variable inspection
* program continuation
* debug symbols generated by the Debug build

### VS Code

The C/C++ debugging workflow is also integrated with VS Code.

Installed extensions include:

```text
ms-vscode.cpptools
ms-vscode.cmake-tools
ms-vscode.cpp-devtools
```

The debugger can be started with `F5`, with breakpoints and variable inspection available through the graphical interface.

Useful shortcuts:

```text
F5   Start/continue debugging
F10  Step over
F11  Step into
```

## Memory Analysis

### Valgrind

Valgrind is installed for dynamic memory analysis.

```bash
valgrind --version
```

It can be used to detect problems such as:

* memory leaks
* invalid memory accesses
* use of uninitialized memory
* invalid frees

Example:

```bash
valgrind --leak-check=full ./build/application
```

Valgrind is complementary to GDB:

```text
GDB      → inspect program execution
Valgrind → analyze runtime memory behavior
```

## Language Server

### clangd

`clangd` provides language-server functionality for C/C++ development.

```bash
clangd --version
```

It provides features such as:

* code completion
* diagnostics
* symbol navigation
* go-to-definition
* references
* semantic analysis

VS Code's C/C++ tooling can use the installed LLVM/Clang toolchain.

## Design Principle

The workstation does not depend on a single compiler.

The intended environment is:

```text
             C/C++ source
                  │
          ┌───────┴───────┐
          │               │
         GCC           Clang
          │               │
          └───────┬───────┘
                  │
              CMake
                  │
               Ninja
                  │
              executable
             /         \
           GDB       Valgrind
```

This provides a portable and reproducible native development environment while keeping the underlying tools independent and replaceable.
